# Dynacademy – AI-Powered Education & Career Guidance Platform

**Live Demo: https://dynacademy.base44.app/dashboard 

---

## Overview

Dynacademy is an AI-powered education and career guidance platform that helps high school learners transition into universities, TVET colleges, and careers. The platform combines AI, data analytics, and educational support tools into one centralized solution.

---

## Problem It Solves

South African learners face limited access to career guidance, poor study support, lack of personalized educational assistance, difficulty with university applications, and limited awareness of bursary opportunities. Dynacademy addresses all these challenges in one platform.

---

## Key Features

**AI Career Guidance** – Recommends careers based on subjects, marks, interests, personality traits, and hobbies.

**APS Calculator** – Automatically calculates APS scores and predicts university eligibility.

**University & TVET Matching** – Matches learners with suitable universities, TVET colleges, and online institutions.

**AI Study Assistant** – Provides summaries, quizzes, study timetables, and AI tutoring.

**Bursary Finder** – Recommends bursaries based on academic performance, financial status, career interests, and location.

**Student Wellness Module** – Supports mood tracking, productivity recommendations, and stress management.

**AI Chatbot** – Answers educational questions in real time.

**Voice Assistant** – Supports speech-to-text interaction for hands-free usage.

**Multilingual Support** – Supports all South African languages.

**Application Deadline Tracker** – Tracks university and bursary deadlines with reminders.

**AI CV & Motivation Letter Generator** – Generates professional CVs, personal statements, and motivation letters.

**Future Jobs Dashboard** – Displays trending careers, salary estimates, and AI-proof careers.

**Accessibility Features** – Includes large text mode, voice navigation, keyboard accessibility, and high-contrast mode.

---

## User Roles

Students access AI tools, career guidance, APS calculator, and study assistant. System administrators manage system configuration and data.

---

## Tech Stack

Frontend uses React, Vite, Tailwind CSS, and Framer Motion. Backend uses Firebase or Supabase for authentication and database. AI processing uses OpenAI API. Data visualization uses Recharts or Chart.js. Application logic uses JavaScript or TypeScript.

---

## System Architecture

The frontend layer provides user interfaces, dashboard views, interactive forms, and data visualizations. The backend layer handles authentication, database communication, AI processing requests, and API integration. The AI processing layer manages career recommendation analysis, chatbot responses, text summarization, and quiz generation. The database layer stores user profiles, academic information, recommendations, and analytics data.

---

## AI Components

The system uses text generation, natural language processing, recommendation systems, and predictive analytics. AI analyzes subjects, marks, interests, personality traits, educational preferences, and career goals. Outputs include career pathways, educational recommendations, summaries, study plans, quizzes, and motivational guidance.

---

## Student Workflow

Student registers or logs in. Student enters academic information. AI analyzes learner data. System generates recommendations. Learner accesses study tools. Dashboard displays analytics and suggestions.

---

## Security & Accessibility

Security includes secure authentication, protected routes, encrypted user sessions, role-based access control, data validation, and secure API communication. Accessibility features include large text mode, keyboard navigation, voice navigation, high-contrast mode, responsive layouts, and screen-reader friendly structure.

---

## Project Impact

Dynacademy improves learner success rates, enhances educational accessibility, increases digital learning support, and reduces educational inequality. It helps underserved communities, rural learners, and financially disadvantaged students. The platform contributes to improved workforce readiness and skills development.

---

## Limitations

The system requires internet connectivity. AI responses may occasionally be inaccurate. It depends on external APIs and is limited by API quotas and usage costs. It cannot fully replace professional educators or counselors.

---

## Future Enhancements

Planned features include mobile applications, advanced AI personalization, integration with university systems, real-time application submissions, expanded language support, AI-powered interview preparation, scholarship application automation, offline support features, enhanced predictive analytics, and LMS integration.

---

## Conclusion

Dynacademy successfully combines artificial intelligence, educational support, career guidance, wellness tracking, university matching, study assistance, and analytics dashboards into one integrated platform for South African learners.
